# django-familyhistory


My personal web application for recording my family history.

This is still a work in progress, but the basics are already set up for:

- Recording people and relationships
- Adding life events and documents
- Auto generating interactive family tree - using [family-chart.js](https://github.com/donatso/family-chart)

Very happy for anyone to reuse and/or send any pull requests etc
